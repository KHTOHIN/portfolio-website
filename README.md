# Kawsar Hamid — Portfolio Website

Personal portfolio website showcasing my experience, projects, skills and certifications as a Software Engineer.

**Live:** [kawsarhamid.vercel.app](https://kawsarhamid.vercel.app)

## Sections

- About
- Tech Stack & Expertise
- Experience
- Projects (live and personal)
- Certifications & Achievements
- Downloadable resume
- Contact

## Features

- Responsive layout for desktop and mobile
- Light / dark theme toggle
- Animated canvas background
- Scroll animations with AOS
- Font Awesome icons

## Tech Stack

HTML5 · CSS3 · JavaScript · AOS · Font Awesome · Deployed on Vercel

## Run Locally

```bash
git clone https://github.com/KHTOHIN/portfolio-website.git
cd portfolio-website
```

Then open `index.html` in your browser — no build step required.
